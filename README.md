# BrandPulse

### AI-Powered Customer Voice Intelligence Platform

> Turn public conversations into actionable customer intelligence.

Built for Wema Bank and ALAT: keyword + timeframe in, classified sentiment/complaint report out — across Google Play, App Store, Nairaland, and YouTube.

## Docs

- `docs/PRD.md` — what we're building, phases, success metrics
- `docs/EngineeringDesign.md` — how every component works: schema, connector interface, storage, classification pipeline
- `CLAUDE.md` — project instructions Claude Code reads automatically every session
- `TASKS.md` — milestone tracker
- `claude/milestones/` — one implementation-ready prompt per milestone

## Build process

This project is built one milestone at a time, each reviewed before the next starts. See `TASKS.md` for the list and `CLAUDE.md` for the ground rules. Don't ask Claude Code to "build the project" — open one milestone file at a time.
